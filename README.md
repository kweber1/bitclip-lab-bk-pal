# Bit-Clip Lab data: Banjo-Kazooie · N64 PAL

Data files for the [Bit-Clip Lab](https://kweber1.github.io/bitclip-lab/?v=pal) viewer (the viewer and the tools that make these files are in [kweber1/bitclip-lab](https://github.com/kweber1/bitclip-lab)). Each game version has its own repository so each gets its own 1 GB GitHub Pages site; the viewer loads from all of them on the same `kweber1.github.io` address.

PAL results and room geometry for every Banjo-Kazooie room: `data/map<map>.gz.wasm` (gzipped JSON; rooms over 15 MB are split into `map<map>.gz.<n>.wasm` parts, joined in order).

Files end in `.wasm` so GitHub Pages serves the gzipped bytes as they are. No game art is published here.
